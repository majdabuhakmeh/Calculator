# Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript. It provides a clean calculator interface with expression evaluation, calculation history, and responsive styling.

## Features

- Addition, subtraction, multiplication, and division
- BODMAS operator precedence
- Results rounded to two decimal places
- One decimal point allowed per operand
- Calculation history with up to four recent entries
- All-clear, clear-entry, and backspace controls
- Division-by-zero error handling
- Responsive layout for smaller screens

## Project Structure

```text
Assignment-4/
├── index.html   # Calculator markup and controls
├── styles.css   # Layout, colors, and responsive styling
├── script.js    # Calculator logic and event handling
└── README.md    # Project documentation
```

## Run Locally

1. Clone or download the project.
2. Open `index.html` in a web browser.

No build tools or external dependencies are required.
